# FastAPI Fundamental

A hands-on learning project for understanding Python fundamentals, building a REST API with FastAPI, and deploying it to an AWS EC2 instance.

## Goals

- Learn Python fundamentals through practical exercises.
- Understand the fundamentals of FastAPI and REST API development.
- Build a simple CRUD API without a database.
- Practice automated testing and API validation.
- Learn the basics of deploying and running an application on AWS EC2.

## Project Scope

This project focuses on the fundamentals of Python and FastAPI.

**Included:**
- Python syntax, data types, collections, and control flow
- Functions, modules, exceptions, decorators, and type hints
- FastAPI routing and request handling
- Request validation and response handling with Pydantic
- In-memory CRUD operations
- Automated testing with pytest and FastAPI TestClient
- Basic AWS EC2 deployment and Linux server operations

**Out of scope:**
- Database integration and ORM
- Authentication and authorization
- Redis and message queues
- Microservices and complex backend architecture

## Technology Stack

## Getting Started

### Prerequisites

- Python 3.14 or a compatible Python version
- Git
- Visual Studio Code or another code editor

### Setup

Clone the repository and navigate to the project directory:

```bash
git clone git@github.com:dzulfanf/fastapi-fundamental.git
cd fastapi-fundamental
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies after the project dependencies have been configured:

```bash
python -m pip install -r requirements.txt
```
